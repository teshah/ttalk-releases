# ttalk Releases

Official public binary releases and 1-click bootstrap for **[ttalk](https://github.com/teshah/ttalk)** (Air-Gapped Standalone Voice Flow Engine for Windows x64).

---

## ⚡ 1-Click Fast Install (Any Windows 10/11 Laptop)

Open **PowerShell** and run this single command:

`powershell
irm https://gist.githubusercontent.com/teshah/919ad5d28858adf2b74a6d889e3f43b3/raw/install.ps1 | iex
`

### What This Does Automatically:
1. Downloads the 100% offline standalone release package (	talk-portable-v0.1.0-alpha.zip).
2. Extracts it cleanly to %LOCALAPPDATA%\ttalk.
3. Creates a **ttalk** shortcut directly on your Desktop.
4. Launches the engine immediately — **zero third-party dependencies required**.

---

## 🗑️ 1-Click Uninstall

To cleanly remove 	talk and its desktop shortcut, run:

`powershell
irm https://gist.githubusercontent.com/teshah/7ad69aebf046b0267f20214200dbd5f5/raw/uninstall.ps1 | iex
`

---

## 📦 Manual Download

If you prefer to run it manually without installing:
1. Download **[ttalk-portable-v0.1.0-alpha.zip](https://github.com/teshah/ttalk-releases/releases/download/v0.1.0-alpha/ttalk-portable-v0.1.0-alpha.zip)** from the [Latest Release](https://github.com/teshah/ttalk-releases/releases/latest).
2. Unzip anywhere (even on a USB thumb drive).
3. Double-click un.bat.
4. Hold **[CapsLock]** in any application to dictate offline.
